# Once Upon a Timeline

A static literature library and installable PWA with 158 works and 1896 story cards.

[Open the library](https://ascendesshady.github.io/English-Literature/)

Painting preview: 113 of 158 books have reviewed painted illustrations (1356 cards). Remaining books use their existing symbolic drawings while their paintings are prepared or corrected. The complete illustration rollout and final storytelling review remain pending.

Read each story through twelve narrated cards, explore the cast and quotations, and save favourites and reading progress in your browser. Every story has an **Author** tab with a concise biography, sources and a licensed historical portrait where available. Joint authorship and unknown authors are identified explicitly; portrait credits and reuse terms are included. Author profiles and portraits are available offline alongside the stories. Use **Install app** in the top navigation on Chrome. Wait for the offline-ready message before reading without a connection. Existing installed readers can choose **Update and reopen** to receive a release; their saved progress is preserved.

This repository contains only the website, story-card data, paintings and app icons. Source documents, Python build tools, research files and image-generation prompts are retained in the author's local workspace. Paintings are WebP; app icons are PNG/SVG. No account, build step, API key or backend is required.

Paintings use compressed WebP at their original dimensions, with one sheet serving all twelve cards of a book. Each panel has measured source bounds and an explicit clip to prevent neighbouring scenes from appearing; readers and cast cards preserve the panel's natural proportions. Packaging enforces a 100 MB website budget and excludes voice models and finished audio recordings. The speech runtime is downloaded only when narration is requested; ordinary reading does not fetch it.

Open `index.html` locally to read. Installation and service-worker caching require the HTTPS site. GitHub Pages can serve these files directly from the repository root.

Choose **Listen** inside any story for gentle, local neural narration. Cards turn automatically when their audio finishes. Pause/resume, stop, replay, voice, pace and Auto turn controls are provided. First use downloads the pinned Kokoro model (about 92 MB) plus the optional browser speech runtime (about 23 MB); no story text is sent to a speech server. Once prepared, the model and runtime work offline in the same browser. The model is fetched from Hugging Face and retained on the device, rather than stored in this repository. Neural narration uses the hosted/installed library; a local file preview links to that library. Software and voice licence notices accompany the runtime assets.

Use **Download audio ↓** in the top navigation, **Download narration** beside installation, or **Download story** in a reader to save finished narration on your device. Select the full library or one story. The default **One voice and pace** keeps storage smaller; **Choose voices and paces** lets you select any subset, and **Every combination** saves both voices at all four paces. The panel shows a progress bar, percentage, completed recording count, saved bytes and remaining-time estimate. Voice setup has its own progress bar. While preparing, the top and reader buttons show progress. Completed recordings survive pauses, reloads and app updates; resumed work skips saved versions. Keep the app open for the first local preparation. Saved cards play without running speech generation again.

The full library has 1,896 recordings for one combination (roughly 1 GB), or 15,168 for every voice/pace combination (roughly 9 GB), plus the shared voice model. A single story has 12 recordings per selected combination. The size shown before starting reflects the actual choices. Audio is prepared and cached in each reader’s browser or installed app; these are not pre-generated server downloads or files placed in the operating system Downloads folder. Normal device audio startup still applies.

In the same top download panel, **Clear saved audio** removes recordings while retaining the voice model and website. **Clear device cache** removes this app’s offline website, voice downloads and recordings in both browser and installed-app modes. Saved shelf and reading progress are kept, and unrelated application caches are preserved. Offline files stay cleared after reopening: choose **Save website offline** or start an audio download to prepare them again. The clearing action asks for confirmation; pause any active preparation first.
