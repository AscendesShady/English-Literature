# Additions identified in the supplied PDF references

Sixty selected literary works absent from the previous 98-work library now have twelve original narrated cards each. Both handbooks also contain many other titles, biographies, historical notes, nonfiction references and exam distractors; this is a curated expansion, not a claim that every named item has been converted. Existing works are retained without duplicate cards. The PDFs remain local reference files and are not redistributed in the website package.

PDF page numbers below count from the first page of the file, including covers and blank pages. Printed handbook numbers can differ. Titles and attributions have been normalised against reading editions.
